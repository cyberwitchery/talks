# talks

talks and workshop material from cyberwitchery.

each directory is one talk: sources, built slides, and any speaker notes or
runnable material, captured as delivered. these are archival, commands and code
in them target the versions current at the time and are not kept in sync with
upstream.

## index

- **dknog-2026**: "alembic demo", the live-demo half of a data-model-first
  network-automation talk (dknog 2026).
- **denog-18**: "network automation for the modern age", data-model-driven
  automation with alembic as the case study, and a live deploy-and-drift demo
  between netbox and containerlab (denog 18).
